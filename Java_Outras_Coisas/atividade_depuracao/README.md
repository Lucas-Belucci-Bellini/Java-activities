# Atividade — Depuração e Documentação (10 pontos)

## A atividade

A classe `Locadora` tem 10 métodos, **todos com um bug pequeno** — lógico ou de execução. 


**O que fazer, para cada um dos 10 métodos:**

1. **Rodar e testar** pelo menu do `Main.java`.
2. **Encontrar e corrigir os bugs.**
3. **Escrever o Javadoc completo** de cada método e das classes `Carro`,
   `Cliente`, `Seguro` e `Locadora. 

Entregar no classroom o projeto zipado. Arquivos necessários para entrega: Carro, Cliente,
Locadora, Main, Seguro (pode mandar somente a pasta src + pom.xml).
